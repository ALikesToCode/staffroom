Staffroom: measuring the on-device check

A developer page. It runs 24 fixed, invented cases through the same on-device check the app uses: 12 where the advice conflicts with a withheld fact and 12 where it does not. Each case runs once; add ?runs=3 to the address to run each three times. Nothing is sent anywhere: the route is ONLY_ON_DEVICE.

Add ?set=full for the second set: the whole sample note, a vault built from fixed entries, and five fixed drafts of five three-step items each, of which one or two in each draft have a step that a withheld fact rules out. Add perFact=1 to ask about one fact at a time. For example eval.html?set=full&perFact=1&runs=3.
